Разработка приложения для ведения рецептов. С поиском, категориями и возможностью составления меню на неделю. 

Репозиторий содержит исходный код курсового проекта. Проект реализован на языке C++ с использованием фреймворка Qt 6 и системы автоматизации сборки CMake.

Архитектура проекта

Приложение разделено на независимые логические модули и имеет клиент-серверную структуру:
* **RecipeServer (Сервер):** Консольное сетевое приложение, функционирующее на базе протокола TCP (`QTcpServer`). 
* **RecipeClient (Клиент):** Графическое приложение на базе Qt Widgets. 
* **RecipeTests (Тесты):** Изолированный исполняемый файл модульного тестирования на фреймворке Qt Test.

Компиляция и сборка проекта

Сборка всех компонентов проекта осуществляется единым циклом через командную строку Windows (`cmd`) с монтированием рабочей директории в контейнер:

#1. Перейдите в папку с вашим проектом на Windows
cd C:\Users\Ваше_Имя\Projects\RecipeApp

#2. Запустите контейнер с монтированием текущей папки
docker run -it --rm -v "%cd%:/home/ubuntu/RecipeApp" --name recipe_env <название-контейнера>:latest bash

#3. Перейдите в привязанную папку
cd /home/ubuntu/RecipeProject

#4. Создание каталога сборки
cmake -B build

#5. Компиляция проекта
cmake --build build

Порядок запуска

Для корректной инициализации сетевых сокетов необходимо соблюдать строгую последовательность запуска исполняемых файлов:

1. Запуск сетевого сервера:
   ./build/server/RecipeServer
   
   Для работы сервера в фоне поставьте в конце команды &, чтобы запустить тесты и клиента в одном окне. Для выключения пропишите команду pkill RecipeServer

3. Запуск модульных Unit-тестов:
   ./build/client/tests/RecipeTests

4. Запуск графического клиента (в новом окне терминала):
   ./build/client/RecipeClient

   Инициализация графического интерфейса пользователя (требуется запущенный X-сервер на хост-машине).
